# Прототип сайта онлайн-школы

Кликабельный макет: главная → каталог → страница курса → запись и оплата → личный кабинет ученика.
Бэкенда нет: формы ничего не отправляют, оплата ненастоящая, прогресс ученика хранится только в браузере.

**Сайт:** https://k41705594-boop.github.io/online-school-prototype/

## Что есть
- Главная: подбор курса за 3 вопроса, путь ученика, преподаватели с видео-знакомством, отзывы, цены, вопросы, заявка на пробный урок.
- Каталог: поиск, фильтры, сортировка, избранное (сердечко).
- Страница курса: программа, результат и сертификат, тарифы (в рассрочку или сразу со скидкой).
- Оформление в 3 шага с промокодом (для проверки: `СТАРТ`) и расчётом суммы.
- Вход по коду из почты (подойдёт любой) или как демо-ученик.
- Кабинет: главная, расписание по неделям, уроки по порядку, домашние задания (сдать → наставник проверит), чат с наставником, прогресс и достижения, сертификат.
- Уведомления, тёмная тема, 5 вариантов цветов.
- Кнопка **«Настроить сайт»**: можно вписать название, направления, цены и выбрать цвета, всё меняется сразу.

## Как поменять тексты и цены
Всё лежит в одном файле: [`js/config.js`](js/config.js). То, что в `[квадратных скобках]`, — заглушки.
Цены пишутся числом за месяц (`mentor: 4900`), `null` означает «[цена]».

## Файлы
- `index.html` — страница
- `css/style.css` — оформление
- `js/config.js` — тексты, курсы, цены
- `js/app.js` — логика
